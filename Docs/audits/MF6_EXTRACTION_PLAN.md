# MF6 Extraction Plan

## Objetivo

Refatorar o MF6 para que ele contenha exclusivamente a especificação normativa do Framework de Modificadores.

## Status

INICIADO

## Regras

- Nenhum conteúdo será removido sem destino definido.
- Nenhuma regra de modificadores será alterada.
- Toda migração deve manter rastreabilidade.
- Toda alteração deve passar pelo validador documental.
